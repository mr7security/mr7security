## Red y detección · Network & detection

| Proyecto | Qué hace | Stack |
|---|---|---|
| **[netscan](https://github.com/mr7security/netscan)** | Escáner TCP asíncrono y fingerprinting de servicios (HTTP/SSH/FTP/SMTP). Salida en tabla o JSON. | Python |
| **[webscan](https://github.com/mr7security/webscan)** | Auditor de postura web y TLS (cabeceras, certificado, cookies). Informe HTML bilingüe. | Python |
| **[shadowscan](https://github.com/mr7security/shadowscan)** | Detector pasivo de Shadow-AI: qué hosts internos contactan con servicios de IA, vía DNS y SNI de TLS. | Python · scapy |
| **[spoofscan](https://github.com/mr7security/spoofscan)** | Auditor de spoofing y autenticación de email (SPF, DKIM, DMARC, MTA-STS), dominios similares y forense de `.eml`. | Python |

## Cómo trabajo

Herramientas read-only y con aviso legal, informe HTML bilingüe (EN/ES) por severidad, salida en JSON/CSV para SIEM, tests y CI donde aplica, y un catálogo o configuración editable para que no se queden obsoletas. Úsalas solo en sistemas propios o con autorización.
