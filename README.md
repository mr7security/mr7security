## Herramientas de seguridad

| Proyecto | Qué hace | Stack |
|---|---|---|
| **[TrailBlazer](https://github.com/mr7security/trailblazer)** | Analizador de huella forense y OPSEC post-explotación. Calcula un OPSEC Score y correlaciona artefactos con MITRE ATT&CK. Windows y Linux. | Python · psutil · rich |
| **[AD Attack Surface Analyzer](https://github.com/mr7security/ad-attack-surface-analyzer)** | Auditoría read-only de Active Directory vía LDAP(S): Kerberoast, AS-REP, delegación, ACLs peligrosas, DCSync. Informe HTML + PDF. | Python · ldap3 |
| **[IAM Risk Analyzer](https://github.com/mr7security/iam-risk-analyzer)** | Postura IAM de Microsoft Entra ID: 16 comprobaciones clasificadas por severidad, con informe HTML estilo pentest. | Python · MSAL · MS Graph |

Ninguna escribe en el sistema auditado. Todas están pensadas para usarse con autorización explícita.

## Simuladores de concienciación

Formación en seguridad para empleados, en un único archivo HTML sin backend ni dependencias. Se abren y se juegan.

|---|---|---|
| **[Phantom Desk](https://github.com/mr7security/phantom-desk)** | Phishing, ingeniería social y fraude del CEO | [Probar](https://mr7security.github.io/phantom-desk/) |
| **[La primera hora](https://github.com/mr7security/primera-hora)** | Respuesta a incidentes: los primeros 60 minutos | [Probar](https://mr7security.github.io/primera-hora/) |
| **[Portapapeles](https://github.com/mr7security/portapapeles)** | Uso seguro de la IA en el trabajo | [Probar](https://mr7security.github.io/portapapeles/) |
| **[Datos con nombre](https://github.com/mr7security/datos-con-nombre)** | Protección de datos en el día a día | [Probar](https://mr7security.github.io/datos-con-nombre/) |

La premisa de todos es la misma: no se aprende viendo un vídeo y aprobando un test. Se aprende tomando la decisión y viendo la consecuencia.
